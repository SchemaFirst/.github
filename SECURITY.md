# Security

If you discover a security issue in SchemaFirst.org infrastructure, schemas, or this GitHub organization, **do not** open a public issue.

Use GitHub's private [vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on the affected repository, or email the maintainers listed on [schemafirst.org](https://www.schemafirst.org).

Please include:

- A description of the issue and impact
- Steps to reproduce
- Any suggested fix

We will acknowledge reports and coordinate disclosure.
