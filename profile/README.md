## What we publish

SchemaFirst separates organizational truth from the tool that happens to consume it. Define once, publish once, and let compatible systems discover, retrieve, and apply only the fields they need.

| Standard | Status |
| --- | --- |
| [Brand Schema](https://www.schemafirst.org/standards/brand-schema) — a Brand Card any compatible AI can retrieve | Available |
| [GTM Data Schema](https://www.schemafirst.org) — shared objects and vocabularies | Available |
| [Standards index](https://www.schemafirst.org) | Browse |

Created in public · Governed by the community · Owned by no vendor
